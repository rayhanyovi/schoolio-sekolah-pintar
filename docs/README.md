# Schoolio Documentation

All canonical documentation is consolidated in **[PLANS.md](PLANS.md)** in this directory. That is the single source of truth for product, architecture, RBAC, design system, and roadmap.

AI agents should start from the root **[llms.txt](../llms.txt)** file, then read `PLANS.md` and **[build_logs.md](build_logs.md)** before continuing work. Append one concise entry to `build_logs.md` after every AI-implemented task.

The `archive/` directory keeps the historical / deep-dive docs (techplan, AUTHZ matrix, OPS playbooks, governance packets, gap analyses) for reference. Do not edit `archive/` files; if a fact changes, update `PLANS.md` instead.
